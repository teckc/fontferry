# FontFerry 产品章程

版本范围和验收见 [当前版本交付单](milestone.md)，实现约束见 [架构与工程约束](architecture.md)。

## 1. 用户与产品承诺

FontFerry（字渡）服务于长期使用一组固定字体的个人用户。首批聚焦 Windows 上的设计师和开发者。典型任务是从原作者处安装一款字体，了解现在使用的版本，决定何时更新，遇到兼容问题时恢复上一版。

首版承诺覆盖少量经核验的字体目录、原作者发布源、当前用户安装、逐字体更新策略与上一版恢复。商业字体或无公开制品的来源提供版本追踪和官方获取入口。macOS 和 Linux 各自通过原生验收后再获得同等产品承诺。

这一定位是待验证的产品判断。第一轮内测观察用户能否独立完成首次安装、能否从失败处继续、敢不敢启用逐字体自动安装。若用户仅安装一次且日后很少回访，应先验证版本维护是否构成持续需求，再扩大目录。

## 2. 管理关系

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| 目录字体 | 有来源定义，用户尚未建立本机管理关系 | 浏览、检查、安装或关注 |
| 已关注 | 用户明确订阅来源，可记录自己确认的安装版本 | 检查、查看官方渠道、停止关注；符合条件时可发起单独安装 |
| 已管理 | FontFerry 的账本明确记录了相应的文件所有权 | 检查、安装可用更新、变更字体包、恢复上一版、移除管理文件 |
| 已管理但受限 | 当前文件、备份、来源或账本存在可定位的问题 | 展示具体原因和仍可用的操作；涉及所有权歧义时进入只读诊断 |

「本机检测到」是观测结果，与这四种关系独立。已有字体、系统字体和同名家族保留原所有权。存在会影响注册或字体选择的冲突时，安装在修改前停止，并指出冲突对象及可由用户采取的操作。目录条目失效或被移除后，用户仍能在「我的字体」找到已管理记录并执行可验证的本地操作。

## 3. 用户任务

| 入口 | 主任务 | 产品能力 |
|---|---|---|
| 我的字体 | 维护已有字体 | 已管理、已关注、需处理。每行显示本机版本、更新检查结果、自动安装状态。详情提供版本操作、恢复入口和该字体的最近记录。 |
| 字体目录 | 找到并安装第一款字体 | 搜索、少量经过验证的目录条目、受控的示例文本、作者和许可、推荐变体、添加自定义源。目录可离线浏览。 |
| 设置 | 配置后台检查、网络、应用更新 | 显示任务是否注册、最近一次运行及结果。提供本机 HTTP 代理、连接测试、应用通道、诊断复制入口。 |

**首次使用。** 无管理记录时引导用户找到并安装一款字体。展示作者、来源、许可和推荐变体。安装完成后，用户能确认实际安装的版本和字体族，并在目标应用中使用它。只提醒来源提供关注和官方获取入口。

**手动更新。** 显示当前版本、目标版本和变体。用户确认后执行该候选。目标、许可或匹配制品变动时重新确认。检查状态至少区分未检查、正在检查、确认无更新、有可用更新、检查失败。失败时显示最近一次成功检查的时间和缓存结果，缓存条目带历史标识。

**后台检查与安装。** 默认由用户决定何时检查和安装。每日检查可覆盖已管理和已关注的字体。用户可逐字体开启自动安装，并查看最近一次任务的逐项结果。

**恢复上一版。** 用户确认回滚即暂停该字体的自动安装，直到主动恢复。离线恢复依赖可验证的本地账本和快照。

**故障。** 反馈包含操作阶段、当前字体状态和下一步。DNS、代理不可连通、上游访问限制、候选变动、文件冲突和待修复状态采用各自的操作入口。若已提交但清理待续，显示实际已提交版本并提供继续恢复。无法确认本机状态时明确显示「待检查」或「需要修复」。

**自定义源。** 输入原始仓库链接，预检实际版本、唯一匹配的制品和许可信息。保存或编辑后立即刷新当前界面。若来源身份变化，应重新确认映射并暂停自动安装。仍有受管理字体时，允许停用来源并保留管理记录。删除关注关系仅影响版本追踪。

**应用更新与卸载。** 下载页和应用内显示已安装版本、通道及下一步。稳定通道缺清单时显示通道不可用和手动入口，测试版由用户明确选择。移除应用停止其后台任务。字体及相应管理账本默认保留。用户可在字体详情先移除选中的管理文件，再移除应用。

## 4. 判断产品是否有用

内测观察首次安装能否独立完成、失败后能否自行恢复、用户是否愿意委托自动更新。记录实际尝试与需要人工协助的步骤，并注明平台、应用版本、网络模式及已有字体情况。用户可主动提供脱敏诊断。错误删除外部字体、未经授权的自动更新或后台覆盖用户刚恢复的版本，均阻断发布。
